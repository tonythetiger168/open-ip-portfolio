## 與既有總合約的相容性
Root_of_Trust_top現有OTP map 0..7=UDS、8..15=image digest、16..31=token hash、32=LC、33=scrap、34=rollback。它沒有總合約root-public-key hash／signature manifest語意，禁止直接重解釋既有fuse；新layout必須有版本及migration/provisioning決策。IMG_AW=14是有限word count，不代表任意長OTA image支援。TEST/RMA的cpu_en與boot_ok不能接PROD release而不再檢查LC。
SHA3文件也不能將cSHAKE/KMAC視為已實作；domain bits不同，前綴編碼不能補足缺少的cSHAKE domain選擇。SHA3不是現有ECDSA-P256/SHA256合約的直接替換。
既有APB wrapper使用ID/IRQ/FLAGS、部分讀取會pop，與總合約無clear-on-read的security service CSR不同；保留IP wrapper，新增服務adapter，不能讓driver誤套兩種CSR。JTAG與HDCP不因此取得key權限。
