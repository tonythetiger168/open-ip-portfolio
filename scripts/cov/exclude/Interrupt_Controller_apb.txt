# Interrupt_Controller_apb coverage exclusions. Structural constants of the AXI4 manager
# (rtl/soc_ss_axi_engine.sv): fixed ID, 32-bit beats (size 2, addresses
# word aligned, all strobes set), INCR bursts, fixed AxPROT, at most 16 beats.
TOGGLE \.m_(aw|ar)id\[ # constant: the manager drives its fixed AXI_ID parameter
TOGGLE \.m_[br]id\[ # tied to the manager's single AXI_ID by the subordinate echo; never varies
TOGGLE \.m_(aw|ar)addr\[[01]\] # constant 0: every access is a word-aligned 32-bit beat
TOGGLE \.m_(aw|ar)len\[[567]\] # constant 0: bursts are at most 16 beats (AxLEN <= 15)
TOGGLE \.m_(aw|ar)size\[ # constant 3'b010: 4-byte beats only
TOGGLE \.m_(aw|ar)burst\[ # constant 2'b01: INCR bursts only
TOGGLE \.m_(aw|ar)prot\[ # constant: the PROT parameter
TOGGLE \.m_wstrb\[ # constant 4'hF: full-word writes only
TOGGLE \.m_[br]resp\[0\] # constant 0: the test memory answers OKAY (00) or SLVERR (10); EXOKAY / DECERR not used
TOGGLE \.m_(ar\w+|r\w+)(\[|:) # read channel unused: this IP only writes (rd_en tied 0 in the engine)
TOGGLE \.c_claim\[([5-9]|[12]\d|30)\] # constant 0: CLAIM is {valid, 26'd0, id[4:0]}
TOGGLE \.m_wdata\[[5-7]\] # constant 0: record bits 7:5 are reserved zeros ({ts, 3'b000, id})
TOGGLE \.m_wdata\[(2[89]|3[01])\] # record timestamp bits 20-23: a free-running clock counter, 2^20 clocks and more
